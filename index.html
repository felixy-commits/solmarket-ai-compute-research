风险解决方案

风险 · 赛事/事件月峰值 2–3×
方案一 · 事件月容量预案（确定执行）

维护全球事件日历（体育、选举、航天节点）。T-28 天：向云厂商锁定弹性 GPU 配额 + CDN 突发带宽包（≥ 日常峰值的 2.5×）。T-7 天：转码队列启用「赛事优先」，新 UGC 默认 720p 以腾挪算力。T-0～T+3：自动扩容至预留容量，值班 SRE 双班；T+3 后 72 小时内缩容至基线。目标：峰值日 P95 播放启动 <2.5s，零主动限流。

风险 · 跨境推理与数据合规
方案二 · 分国数据平面 + API 商品化（确定架构）

部署三套区域面：MENA（主）、欧盟、东南亚 — 推理、索引、日志不跨境混用；用户注册国标签强制路由。对外仅售聚合概率 Feed / 推理 API（无 PII），结算USDC + API Key 计量，主路径不发证券型协议 Token。每季度第三方合规审计 + 分国 DPA；美国维持 view-only 直至牌照路径明确。

风险 · GPU 交货 8–16 周
方案三 · 双轨供应与库存缓冲（确定采购节奏）

Y1 Q4：签署 12 个月云 GPU 框架协议（AWS/GCP，备选 Nebius/CoreWeave）。B 轮交割后 90 天内：下自建转码/推理物理机订单（首批覆盖 100 万用户档 60% 峰值）。永久保留15% 云 burst 池作故障切换；colo 备件 ≥ 在线节点 10%。采购 SLA：关键部件 RTO <4 小时，避免单供应商锁死。

决策摘要：算力可行且与资本节奏可对齐 — Pre-Seed 证云方案，B 轮锁 GPU 资产，IPO 披露算力毛利率与 B2B Token 收入。路径：产品 M6 盈利 → A 扩 AI → B 自建 → C/IPO 规模化出海。
